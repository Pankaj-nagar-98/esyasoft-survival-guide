## 📖 Executive Overview

**The Esyasoft Survival & Thriving Guide** is a modern, highly engaging, interactive web application engineered by a **team of 6 fresh joiners** who have survived their first 15 days (Day 1–2 Induction + Domain Training from 9th–23rd) of a 3-month training program at **Esyasoft Holding**.

Designed with an authentic "elder sibling" tone—practical, humorous, relatable, yet corporate-appropriate—this digital application replaces obsolete 40-slide static PowerPoint decks and dry PDF manuals with an interactive onboarding dashboard.

## 🌟 Key Interactive Modules & Features

### 1. ⚡ Hero Header & Real-Time Intelligence
- **Dynamic Time-Aware Greeting:** Greets the fresher based on local time (Morning, Afternoon, Evening) with situational advice.
- **Batch Metric Counters:** Displays real-time progress (`15 / 90 Days Completed • 16.7% Grid Ready`), `50M+ Endpoints`, and `0 Salary Flags`.
- **Global Instant Search Bar:** Real-time fuzzy filtering across all survival tips, MDM jargon, cafeteria rules, and campus facilities.
- **Embedded Batch Video Showcase:** Responsive 16:9 video container pre-configured with YouTube embed support. Includes a 1-click **"Change Video Link"** modal allowing the team to paste their batch intro or accommodation video.

### 2. 🚨 Check-In / Check-Out Rule Tracker (The Prabhu Compliance Engine)
- **The Golden Quote Banner:** Prominently displays:  
  `"If you forgot to check in check out you won't get salary! ~ Prabhu"`
- **Virtual Biometric Fingerprint Simulator:** Visual laser-scanning animation with authentic synthesized Web Audio chime.
- **Interactive Punch IN & Punch OUT:** Logs daily morning and evening timestamps, saved persistently to browser `localStorage`.
- **Status Indicator:** Switches between `COMPLIANT & FULLY SALARIED 💸`, `IN OFFICE (PENDING CHECK-OUT) 🕒`, and `NOT PUNCHED IN TODAY ⚠️`.
- **Interactive Salary Risk Slider:** Move the slider from 0 to 60 minutes late to preview Prabhu's reaction escalations and salary risk.
- **Daily Reminder Alert:** Configurable alert banner to remind freshers at 8:50 AM and 6:40 PM.

## 🚀 How to Run the Application

## 🚀 Running the Project Locally

This application is built with **React 18, Vite, and Tailwind CSS**.

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or newer recommended)

### Quick Start
```bash
# 1. Clone the repository
git clone <your-repo-url>
cd esyasoft_survival_guide_app

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
# Open http://localhost:3000 in your browser
```

### Production Build
```bash
# Compile and bundle static assets
npm run build

# Preview production build locally
npm run preview
```

## 🛠️ How to Personalize for Your Batch

1. **Add Your Accommodation Video:**
   - Click the **"Change Video Link"** button on the Hero or Accommodation card.
   - Paste your YouTube video link (e.g., `https://www.youtube.com/watch?v=YOUR_VIDEO_ID` or Shorts link).
   - Click **Save & Embed**.

2. **Add Your Beach & View Photos:**
   - Scroll to **Weekend Escapes & Exploration**.
   - Click **"Add Batch Photo / Memory"**.
   - Choose a photo from your laptop or paste an image URL, add a title and description, and click save.

3. **Personalize the 6 Freshers' Names:**
   - Click **"Customize Team"** in the top navbar or under the Networking tab.
   - Enter your actual cohort members' names and roles.
   - The entire dashboard and the **Prabhu Certificate** will dynamically reflect your names!
